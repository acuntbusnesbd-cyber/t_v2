# কাজকর্ম (KajKormo) — ফায়ারবেস চালিত বাংলা টাস্ক ম্যানেজমেন্ট প্ল্যাটফর্ম

সম্পূর্ণ বাংলা ইন্টারফেস, ফায়ারবেস অথেনটিকেশন, ক্লাউড ফায়ারস্টোর ডেটাবেস এবং শক্তিশালী ডেটা আইসোলেশন ও সিকিউরিটি রুলস সমৃদ্ধ একটি পূর্ণাঙ্গ টাস্ক ম্যানেজমেন্ট ওয়েব অ্যাপ্লিকেশন।

---

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Features)

1. **সম্পূর্ণ বাংলা ইউজার ইন্টারফেস (Bangla UI)**:
   - প্রতিটি বোতাম, লেবেল, ফিল্ড, স্ট্যাটাস ব্যাজ, এলার্ট এবং তারিখ-সময় শতভাগ পরিশীলিত বাংলা ভাষায় উপস্থাপিত।
   - ডার্ক ও লাইট মোড (Dark / Light Mode) টগল।

2. **নিরাপদ প্রমাণীকরণ (Firebase Authentication)**:
   - মোবাইল নম্বর ও ওটিপি (SMS OTP) দিয়ে সরাসরি লগইন।
   - ইমেইল ও পাসওয়ার্ড দিয়ে নিবন্ধন এবং লগইন।
   - গুগল এক-ক্লিক সাইন-ইন (`signInWithPopup`)।
   - সুরক্ষিত রাউটিং — লগইন ছাড়া ড্যাশবোর্ডে প্রবেশ বা ডেটা পড়া অসম্ভব।

3. **ক্লাউড ফায়ারস্টোর CRUD এবং ইউজার আইসোলেশন**:
   - কাজ তৈরি (Add), দেখা (View/List), সম্পাদনা (Edit), এবং মুছে ফেলা (Delete)।
   - প্রতিটি টাস্কের সাথে `userId` সংযুক্ত।
   - `firestore.rules` দ্বারা সুরক্ষিত: কোনো ব্যবহারকারী অন্য কোনো ব্যবহারকারীর কাজ পড়তে বা পরিবর্তন করতে পারবেন না।

4. **টাস্কের গুরুত্বপূর্ণ ক্ষেত্রসমূহ (Fields)**:
   - **শিরোনাম (Title)**: সর্বোচ্চ ২০০ অক্ষর।
   - **বিবরণ (Description)**: বিস্তারিত নোট বা চেকলিস্ট।
   - **গুরুত্ব (Priority)**: উচ্চ (High) / মাঝারি (Medium) / কম (Low)।
   - **অবস্থা (Status)**: অসম্পূর্ণ (Pending) / চলমান (In Progress) / সম্পন্ন (Completed)।
   - **শেষ সময় (Deadline / Due Date)**: তারিখ ও সময় পিক করার সহজ ইন্টারফেস।

5. **স্মার্ট নোটিফিকেশন ও ডেডলাইন এলার্ট**:
   - ব্রাউজার ওয়েব পুশ নোটিফিকেশন সমর্থন।
   - সময় পার হয়ে যাওয়া কাজের জন্য ভিজ্যুয়াল পালসিং এলার্ট ও কাউন্টডাউন।
   - কাজ সম্পন্ন করলে অডিও চাইম ও আনন্দদায়ক কনফেটি অ্যানিমেশন।

6. **অ্যাক্টিভিটি ড্যাশবোর্ড ও অফলাইন সহায়তা**:
   - মোট কাজ, সম্পন্ন, চলমান, অসম্পূর্ণ, উচ্চ গুরুত্ব ও সময় পার হওয়া কাজের রিয়েল-টাইম পরিসংখ্যান।
   - পার্সেন্টেজ প্রগ্রেস বার।
   - ইন্টারনেট সংযোগ বিচ্ছিন্ন হলেও কাজ চালিয়ে নেওয়ার সুবিধা (Offline Persistence)।

## 🚀 যেভাবে সেটআপ ও রান করবেন (How to Run)

### ১. ডিপেন্ডেন্সি ইন্সটল
```bash
npm install
```

### ২. ডেভেলপমেন্ট সার্ভার চালু
```bash
npm run dev
```
সার্ভার চালু হলে ব্রাউজারে `http://localhost:3000` এ অ্যাপটি ওপেন করুন।

### ৩. প্রোডাকশন বিল্ড
```bash
npm run build
```

## 🛡️ ফায়ারস্টোর সিকিউরিটি রুলস (Firestore Security Rules)
অ্যাপটির সাথে `firestore.rules` ফাইলটি ক্লাউডে স্বয়ংক্রিয়ভাবে ডিপ্লয় করা রয়েছে। রুলসের উল্লেখযোগ্য বৈশিষ্ট্য:
- **Default Deny**: ডিফল্টভাবে সম্পূর্ণ ডেটাবেস রিড/রাইট ব্লক।
- **User Scoping**: শুধুমাত্র `request.auth.uid == resource.data.userId` শর্ত পূরণ হলে তবেই টাস্ক পড়ার ও লেখার অনুমতি রয়েছে।
- **Anti-Spoofing**: ক্লায়েন্ট থেকে অন্য কোনো ইউজারের `userId` বা অসঙ্গত টাইমস্ট্যাম্প পাঠানো হলে ডেটাবেস স্বয়ংক্রিয়ভাবে বাতিল করে।
